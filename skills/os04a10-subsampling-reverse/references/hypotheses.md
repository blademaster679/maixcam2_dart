# 提出可证伪的降采样假设

证据分为：本板已测、OS04A10定义/源码、其他型号类比、纯结构猜测。后二者允许用于用户已授权的易失性数字字段试验，不能在构建manifest中改成“厂商确认”。不要把重复分支代码当成多个独立来源。

## 首轮假设树

| 分支 | 候选与观察 | 判别方式 |
| --- | --- | --- |
| H0 输出窗口控制 | 只改已知输出尺寸和接收几何，保持采样字段 | 得到尺寸变化/裁剪的负对照；不是目标方案 |
| H1 步进类字段 | 将0x3814..0x3817当作“可能的奇偶像素/行步进”候选；不预设它们的轴向或生效条件 | 单个字段1→3作为初始数值猜测；先观察横向/纵向尺度、可见边缘、重排或无响应 |
| H1b 配套字段 | 单字段结果显示奇偶相位异常或需配对时，提出有预测的最小组合 | 与H0及单字段结果比较，保留未改位；不得直接把四字段全设3并宣称2×2 |
| H2 使能/锁存 | H1读回成功但无空间变化时，研究可能的数字采样使能、stream-on锁存或初始化顺序 | 从同型号最终状态差异及类比中列出少量具体位；已知mirror/HDR位保持不变，解释每个新增位的预测 |
| H3 更高降采样 | H1/H2至少一种空间降采样可重复后，研究更大步进或binning＋skipping | 7等值只能是新假设，不是OS04A10已知合法编码；验证新Bayer排列及有效覆盖范围 |

0x3814..0x3817只是地址候选，不是已确认的OS04A10步进寄存器。1→3可表示只翻转bit1（mask0x02），但也可能改变完全不同的功能。还需核对实际基线读回和其他模式写入；写入不存在或只读地址时不得自动尝试相邻地址。

## 控制混杂因素

一次改变一个假设因子，而非机械限制只能写一个寄存器。输出宽高、stride、MIPI/VIN声明和池大小可能必须成组改变，须作为固定的伴随修改列出；H0使用相同伴随修改，以隔离采样字段的效果。

最初保持完整阵列地址、基线PLL、HTS/VTS、HDR、位深、lane、镜像、模拟控制不变。使用相同手动曝光和增益，禁止AE修改未知候选字段；曝光还应满足帧长预算。允许失败图像或无帧提供信息，不把失败结果强行匹配预期尺寸。

不把模拟控制、供电、OTP/熔丝、未明用途的测试模式混入初始搜索；若后来需要模拟配套，先使用已知同型号模式的具体组合并单独论证副作用。没有新线索时，不扩大成0x3600～0x5fff范围扫描。

## 正负预测都要写

每个候选应回答：哪一个观察支持假设，哪一个观察排除当前组合，什么结果仍然不确定。例如：

- 读回变为3但图像与同尺寸H0一致：说明写入被保存，不能证明空间采样改变；排查其他使能/锁存条件。
- 边缘视野变大、局部尺度缩小：支持降采样；若仅一个轴变化，先研究该轴映射。
- 图像重复列、黑边、彩色棋盘、半帧：可能存在几何/奇偶相位/输出长度配套错误，不据此直接判定芯片不能降采样。
- 无帧：首先判断传感器流、MIPI错误、包尺寸和VIN配置；一次无帧只能排除当前完整组合在本次条件下工作。

672×380来自2688×1520的有效4倍空间降采样算式，1344×760来自2倍算式。两者都不是已知可用模式，也不必是含处理边界的实际输出尺寸。先验证机制，再确定边界、对齐和640×360输出链路；等比例保留视野可使用留边，禁止暗中裁掉边缘。
