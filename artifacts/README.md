# 验证产物的版本管理

本目录按测试批次保存本地验证材料。Git 只保留本说明文件，批次目录中的报告、
JSON/CSV 测量摘要、校验清单、PNG/PDF 图表、预览图、视频、原始帧和压缩包均不提交。
根目录的 `reports/` 和 `recordings/` 也整体忽略；测试代码、分析脚本和工具说明继续
保留在 `tests/`、`tools/` 等源码目录中。

忽略和取消索引跟踪不会删除本地文件，但新克隆仓库不会下载这些资料。技术文档中
指向这些目录的相对链接仅在已复制相应材料的本地工作区可用。

换电脑或交付完整证据时，需要单独复制相应批次的报告、摘要、图表、原始数据和录像，
以及报告引用的 `.maixpy/runs/` 原始记录；保留相对目录结构。已有 `SHA256SUMS.txt`
或视频验证 JSON 可用于核对文件。不要打包整个 `.maixpy/`：该目录还包含本地设备
配置、凭据、SDK 副本和临时构建。

新增测试输出统一写入 `artifacts/<测试批次>/`、`reports/` 或 `recordings/`。
不要使用 `git add -f` 强制提交这些产物。此前已提交的材料仍存在于 Git 历史中，
本次取消跟踪只影响后续提交，不重写历史。
