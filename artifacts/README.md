# 验证产物的版本管理

本目录按测试批次保存验证材料。Git 保留 Markdown 报告、JSON 测量摘要、校验清单，以及报告引用的小型 PNG/PDF 图表和预览图。

视频、原始帧和证据压缩包由根目录 `.gitignore` 排除，继续保留在本机，不会因忽略规则而删除。各报告中的视频和压缩包链接是本地相对路径；仅克隆仓库不会下载这些文件。

换电脑或交付完整证据时，需要单独复制相应批次的录像、压缩包，以及报告引用的 `.maixpy/runs/` 原始记录。已有 `SHA256SUMS.txt` 或视频验证 JSON 可用于核对文件。不要打包整个 `.maixpy/`：该目录还包含本地设备配置、凭据、SDK副本和临时构建。

- `os04a10_retest_20260908/`：后续复测、录像、小型图表和恢复核验。
